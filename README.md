# Установка Keenetic NFQWS с Web-интерфейсом

Данный проект позволяет установить **Keenetic NFQWS** с web-интерфейсом на маршрутизатор Keenetic.
Добавлено:
1) Проверка доменов в .list на доступоность
2) Синтаксис в файле .conf
3) Создание и удаление файлов (.conf|.list) через интерфейс

## 📌 Требования
- Маршрутизатор Keenetic с поддержкой установки сторонних приложений (Apps).
- Доступ к веб-интерфейсу маршрутизатора (по умолчанию `http://192.168.1.1`).
- Доступ по **FTP** или через веб-интерфейс Apps.

---

## 🚀 Установка

### 1. Подготовка файлов NFQWS
- Скачайте и установите **nfqws-keenetic** с [репозитория](https://github.com/Anonym-tsk/nfqws-keenetic).
- Скачайте файлы проекта **nfqws-theme** с [репозитория](https://github.com/disasdter/Keenetic-NFQWS-Theme).
- Распакуйте архив (если требуется).

### 2. Подключение к маршрутизатору
#### Способ 1: Через веб-интерфейс Apps
1. Откройте в браузере:  
   `http://192.168.1.1/apps`
2. В разделе **"Файлы"** выберите диск, куда будет установлен NFQWS.

#### Способ 2: Через FTP
1. Подключитесь к маршрутизатору по FTP:  
   - Хост: `192.168.1.1`  
   - Логин/пароль: учётные данные вашего маршрутизатора.
2. Перейдите в папку:  
   `/share/www/nfqws/`

### 3. Загрузка файлов
1. Скопируйте все скачанные файлы NFQWS в папку:  
   `/share/www/nfqws/`

---

## 🌐 Запуск и использование
- После загрузки файлов web-интерфейс будет доступен по адресу:  
  `http://192.168.1.1:90/`
- Откройте этот адрес в браузере для управления NFQWS.

---

## ⚙️ Возможные проблемы
1. **Порт 90 недоступен**  
   Проверьте, не занят ли порт другим приложением.  
   Можно изменить порт в конфигурации NFQWS.

2. **Файлы не отображаются в веб-интерфейсе**  
   Убедитесь, что файлы скопированы в правильную директорию:  
   `/share/www/nfqws/`

3. **Доступ к Apps отсутствует**  
   Проверьте, включена ли опция **"Разрешить установку приложений"** в настройках маршрутизатора.
